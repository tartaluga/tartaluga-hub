# ADR-006: Стек фронтенда

**Статус:** Принято (2026-09-23)
**Дата:** 2026-09-23
**Решает:** владелец

## Контекст
Код пишет и поддерживает ИИ-ассистент, а владелец ревьюит. Значит, нужны популярные, хорошо известные модели инструменты с сильной типизацией и минимумом «магии». Хостинг — только статика (GitHub Pages).

## Решение
| Роль | Выбор | Почему |
|---|---|---|
| Сборка | Vite | Стандарт, быстрый dev-сервер, простой конфиг |
| UI | React 19 + TypeScript (strict) | Самая знакомая ИИ связка. Типы ловят ошибки до запуска |
| PWA | vite-plugin-pwa (Workbox), `registerType: 'prompt'` | Манифест и service worker. Пользователь сам нажимает «обновить», поэтому старая версия не висит молча |
| Роутинг | React Router, hash-режим | GitHub Pages не умеет SPA-фолбэк, а hash не даёт 404 |
| Состояние | Zustand | Мало кода, без провайдеров |
| IndexedDB | idb | Тонкая типизированная обёртка |
| Анимации | Motion (`motion/react`) | Shared element (`layoutId`), жесты, `useReducedMotion` |
| Стили | CSS-переменные + CSS Modules | Темы — смена переменных. Никаких рантайм-CSS-in-JS |
| Шрифты | Inter + JetBrains Mono через `@fontsource` | Локально, работают офлайн, без внешних запросов (CSP) |
| Иконки | Phosphor (`@phosphor-icons/react`) | Как в выбранном макете «1a Визор» |
| Контракт | JSON Schema → типы через `json-schema-to-typescript`, проверка Ajv | Один источник правды (ADR-003) |
| Id | `ulid` | Сортируемые по времени id |
| Тесты | Vitest (логика), Playwright (скриншоты и сценарии) | |

Все зависимости ставятся локально в проект. В CI используется `npm ci` с lock-файлом.

## Рассмотренные альтернативы
- **Tailwind:** удобен, но разметка перегружается классами, и ревьюить её тяжелее. Темы через переменные у нас и так.
- **SvelteKit / Solid:** меньше бандл, но хуже знакомы ИИ и меньше экосистема.
- **Dexie вместо idb:** мощнее, но нам не нужны запросы по индексам.

## Последствия
- Бандл около 200 КБ gzip, для PWA с кэшем это нормально.
- Обновления зависимостей — раз в несколько месяцев через Dependabot в репо приложения.
