# Архитектурные решения (ADR)

Каждый файл — одно решение: контекст, варианты, что выбрали и почему.

Правила изменения:
- **Предложено** (черновик на ревью) — правим прямо в файле. Существенные правки помечаем в тексте строкой «*Исправлено ГГГГ-ММ-ДД: что и почему*», чтобы было видно, что менялось.
- **Принято** — файл больше не переписываем (кроме опечаток и отметок в «Действиях»). Если решение меняется, пишем новый ADR, а в старом ставим статус «Заменён ADR-NNN».
