### B2. JSON Schema v1 и типы — M
**Описание:** `schema/project`, `idea`, `settings`, `status` с `schemaVersion`, ULID-id, `additionalProperties: true`. Генерация TS-типов скриптом. Примеры валидных и невалидных файлов.

### B3. Кодек base64/UTF-8 — XS ⚠ высокий риск
**Критерии:**
- [ ] Круговой тест: кириллица, эмодзи, пустая строка, 1 МБ текста
**Зависит от:** B1

### B4. GitHub-клиент — M ⚠ высокий риск
**Описание:** загрузка дерева, чтение файла, PUT с sha, атомарный мультифайловый коммит (Git Data API), raw-чтение картинок. Все запросы `no-store`, последовательная очередь запросов на запись, типизированные ошибки (401 / 404 / 409 / 422 / сеть).
**Критерии:**
- [ ] Юнит-тесты на моках fetch для каждого пути ошибок
- [ ] Ручной тест на реальном репо данных: прочитать, записать, атомарный коммит из 2 файлов
- [ ] Создание повторяемо (schema/README.md, правило 6): PUT без sha упал, потому что файл уже есть → перечитать; то же содержимое — успех, другое — ошибка «уже существует», без перезаписи
**Зависит от:** B3, A3

### B5. Модуль записи (store) — M
**Описание:** Zustand-стор + единая точка `save(path, data)`. Хранит sha и базовую копию, валидирует каждый файл отдельно, сохраняет незнакомые поля, отказывается писать файл с `schemaVersion` выше своей и битые файлы. Кэш в IndexedDB (пока без очереди).
**Критерии:**
- [ ] Тест: файл с незнакомыми полями после правки сохраняет их
- [ ] Тест: битый файл → карточка ошибки, остальные файлы загружаются
- [ ] Тест: `schemaVersion: 99` → только чтение
**Зависит от:** B2, B4

### B6. Дизайн-токены и оболочка — M
**Описание:** токены цветов, шрифтов и отступов из «1a Визор» для тёмной темы + светлая тема. Переключатель авто / тёмная / светлая. Боковая навигация (ПК) и нижняя (телефон). Логотип-визор. Индикатор SYNC. `useReducedMotion` глобально.
**Критерии:**
- [ ] Оболочка визуально совпадает с `design/1a-vizor-today.webp`
- [ ] 375 px: нижняя навигация, нет горизонтального скролла
- [ ] Контраст текста ≥ 4.5:1 в обеих темах
**Проверка:** скриншоты 4 комбинаций
**Зависит от:** B1

### Чекпоинт B
- [ ] Все тесты зелёные, сборка чистая, деплой работает
- [ ] Скриншоты оболочки владельцу
